Generating SECRET_KEY

Run this locally and paste the output as the value:

python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"

Keep this value out of git and out of any shared document. It signs every JWT and session cookie, so anyone holding it can forge a login. Set it only in Render's Environment tab. Changing it later logs everyone out.

Health check

Under Advanced, set Health Check Path to /healthz/

Create Web Service. First build takes 5–10 minutes.

When it shows Live, copy its URL from the top of the page — e.g. https://medidesk-api.onrender.com

Without this, refreshing any page other than the home page returns 404.

4Connect the two

Go back to medidesk-api → Environment and add the two variables you skipped, using your static site URL:

KeyValue
CORS_ALLOWED_ORIGINShttps://medidesk-web.onrender.com
CSRF_TRUSTED_ORIGINShttps://medidesk-web.onrender.com

Save Changes — the service redeploys automatically.

Include https:// and no trailing slash. A bare hostname is rejected and the browser blocks every request.

9Known limits

  • API sleeps after 15 min idle — next request takes ~50 s.
  • Free Postgres is deleted after 90 days. Back up with pg_dump "$DATABASE_URL" > backup.sql.
  • Uploaded documents are lost on every redeploy.

Redeploy = git push origin main. Migrations run automatically. Settings for all three services are also committed in render.yaml.
