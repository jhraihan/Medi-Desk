# Screenshots

The main README links to four images in this folder. Add them with these exact
filenames and they will appear automatically:

| Filename | What it shows |
|---|---|
| `login.png` | The sign-in page with the demo account buttons |
| `admin-dashboard.png` | The admin dashboard with stat tiles |
| `appointments.png` | The appointments list with filters |
| `patient-dashboard.png` | The patient dashboard |

Keep each image under about 1 MB so the repository stays small. PNG or JPG both work.
